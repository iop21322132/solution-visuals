# Custom Hitbox Feature

## Описание
Добавлена новая функция **Custom Hitbox** в категорию Visual с полным набором настроек.

## Добавленные файлы

### 1. NumberSetting.java
- Новый тип настройки для числовых значений с слайдером
- Поддерживает минимальные/максимальные значения и шаг изменения
- Интерактивный слайдер с перетаскиванием

### 2. ListSetting.java  
- Настройка для группы подкатегорий
- Поддерживает сворачивание/разворачивание списка
- Каждая подкатегория - отдельная BooleanSetting

### 3. CustomHitbox.java
- Основной класс функции Custom Hitbox
- Рендерит хитбоксы сущностей в 3D мире
- Поддерживает настройку размера, цвета и типов сущностей

## Настройки Custom Hitbox

### 1. **Включение/выключение**
- Основная настройка для активации функции
- Интегрирована в главное меню настроек

### 2. **Убрать линию взгляда** 
- BooleanSetting для скрытия линии направления взгляда сущностей
- По умолчанию: выключено

### 3. **Размер**
- NumberSetting для масштабирования хитбоксов
- Диапазон: 0.1 - 3.0
- Шаг: 0.1
- По умолчанию: 1.0

### 4. **Что показывать**
- ListSetting с подкатегориями:
  - **Игроки** (включено по умолчанию)
  - **Мобы** (включено по умолчанию) 
  - **Животные** (выключено по умолчанию)
  - **Предметы** (выключено по умолчанию)

### 5. **Цвет**
- ColorSetting для настройки цвета хитбоксов
- По умолчанию: красный
- Поддерживает полную палитру цветов

## Технические детали

### Рендеринг
- Использует событие `RenderWorldLastEvent` для отрисовки в 3D мире
- Рендерит контуры хитбоксов с помощью OpenGL линий
- Поддерживает интерполяцию позиций для плавности
- Автоматически исключает игрока из отображения

### Интеграция с GUI
- Все настройки автоматически отображаются в главном меню
- Поддержка перетаскивания для NumberSetting
- Интеграция с системой сохранения/загрузки конфигурации

### Производительность
- Эффективная фильтрация сущностей по типам
- Оптимизированный рендеринг только видимых хитбоксов
- Минимальное влияние на FPS

## Использование

1. Откройте GUI мода (по умолчанию клавиша настраивается в настройках)
2. Найдите настройку "Custom Hitbox" 
3. Включите функцию
4. Настройте дополнительные параметры по желанию:
   - Размер хитбоксов
   - Типы отображаемых сущностей  
   - Цвет хитбоксов
   - Отображение линии взгляда

## Совместимость
- Полностью совместимо с существующей системой настроек
- Не конфликтует с другими функциями мода
- Поддерживает сохранение настроек в конфигурационный файл
