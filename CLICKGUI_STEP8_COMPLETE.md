## 8.3 Particle Effects при Действиях ✨

**Файлы**: `InterfaceScreen.java`, `ModuleComponent.java`

**Что добавлено:**
1. **Класс ActionParticle**
   - Частицы разлетаются во все стороны
   - Размер: 2-4px
   - Lifetime: 800ms
   - Физика: замедление + гравитация
   - Fade out эффект

2. **Эффект при включении/выключении модуля**
   - 8-12 частиц при каждом переключении
   - Цвет: акцентный если включен, серый если выключен
   - Позиция: центр модуля
   - Разлетаются радиально

3. **Публичный API**
   - Метод `spawnActionParticles(x, y, color, count)`
   - Можно использовать для других действий
   - Частицы автоматически удаляются после смерти

4. **Оптимизация**
   - Частицы удаляются когда lifetime > MAX_LIFETIME
   - Не рендерятся если alpha < 0.01
   - Легковесные вычисления

**Результат**: Визуальная обратная связь при действиях

## Технические Детали

### Search Bar Анимации

```java
// Glow animation
glowAnimation.run((focused || hovered) ? 1 : 0);

// Свечение
blur.render(...
    .softness(4f)
    .color(TempColor.getClientColor().alpha(alpha * glowValue * 0.15f))
);

// Анимированная рамка
.thickness(2.5f + focusValue * 0.5f)
```

### Tooltip Структура

```java
// Двухстрочный layout
nameFont.drawCenteredString(..., moduleName, ..., y + 3f, ...);
descFont.drawCenteredString(..., description, ..., y + 12f, ...);

// Адаптивная ширина
float barW = Math.max(nameW, descW) + 24f;
barW = Math.min(barW, width);
```

### Action Particles Физика

```java
// Случайное направление
float angle = Math.random() * Math.PI * 2;
float speed = Math.random() * 2f + 1f;
vx = cos(angle) * speed;
vy = sin(angle) * speed;

// Замедление + гравитация
vx *= 0.95f;
vy *= 0.95f;
vy += 0.1f;
```

## Дополнительные Возможности

### API для Particle Effects

Теперь можно создавать эффекты частиц в любом месте:

```java
InterfaceScreen gui = getClickGUI();
gui.spawnActionParticles(x, y, color, count);
```

**Параметры:**
- `x, y` - позиция эффекта
- `color` - цвет частиц
- `count` - количество частиц

**Примеры использования:**
- При переключении категории
- При изменении настройки
- При сохранении конфига
- При любом другом действии
