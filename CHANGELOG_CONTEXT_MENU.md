## 🎮 Как использовать

1. Модуль **включен по умолчанию**
2. Откройте **чат** (T) или **ClickGUI** (Insert)
3. Нажмите **ПКМ** в любом месте
4. Меню появится с плавной анимацией!
5. Выберите пункт или нажмите **ESC**

### Анимация
```java
// Каждый кадр обновляем анимации
scaleAnimation.run(1f);   // Масштаб 0 → 1
alphaAnimation.run(1f);   // Прозрачность 0 → 1
wobbleAnimation.run(1f);  // Покачивание

// При закрытии
scaleAnimation.run(0f);   // Масштаб 1 → 0
alphaAnimation.run(0f);   // Прозрачность 1 → 0
```
