## 🎯 Как применить к своему модулю

Если у вас есть модуль с ColorSetting, просто убедитесь что:

1. **Текстуры (ListSetting)** - добавьте ПЕРВЫМИ в getSettings()
2. **Слайдеры (SliderSetting)** - добавьте ВТОРЫМИ
3. **Цвет (ColorSetting)** - добавьте ТРЕТЬИМ

```java
public MyModule() {
    super("My Module", Category.Render, "...");
    
    // Порядок добавления = порядок в GUI!
    getSettings().add(textures);      // 1️⃣ Текстуры первыми
    getSettings().add(slider1);       // 2️⃣ Ползунки вторыми
    getSettings().add(slider2);
    getSettings().add(colorSetting);  // 3️⃣ Цвет третьим (коллапсирующийся!)
}
```

## 🖱️ Как использовать цветник

1. **Открытие**: Нажмите на цветной квадрат (слева от текста "Цвет")
2. **Выбор цвета**: Кликайте в круге или дергайте ползунки
3. **Закрытие**: Нажмите на квадрат еще раз

**Ввод HEX кода**: Нажмите на текст `#RRGGBB` внизу цветника (появится мигающий курсор для ввода)

## 🔧 Технические детали

### Файл: ColorSettingComponent.java
- Убрана кнопка "Цвет"
- Добавлена логика `expanded` для toggle
- Клик на swatch (квадрат) переключает состояние
- Высота автоматически меняется (компактная ↔ расширенная)

### Файл: JumpCircle.java
- `texture` поле перенесено в начало класса (первое)
- Остальные поля в нужном порядке
- Порядок полей = порядок отображения в GUI

## ⚠️ Важно

**Не путайте порядок в коде с порядком в GUI!**

✅ **ПРАВИЛЬНО**: Порядок в `getSettings().add()` определяет порядок в GUI
❌ **НЕПРАВИЛЬНО**: Порядок объявления полей (если они не добавляются явно)

Если модуль использует `@ModuleInfo` и поля `public final`, то порядок определяется порядком полей в классе (как в JumpCircle).
