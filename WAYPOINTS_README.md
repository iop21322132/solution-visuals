# WayPoints - GPS система для Solution Visuals

## Описание
WayPoints - это модуль GPS навигации, который позволяет создавать точки на карте и видеть их в 3D мире с красивой визуализацией.

## Возможности
- ✅ Создание waypoints через команду `.gps`
- ✅ Красивая 3D визуализация с рамкой и шейдерами
- ✅ Стрелка, указывающая на блок (повернута на 180° вниз)
- ✅ Отображение расстояния до точки
- ✅ Настраиваемые цвета и размеры
- ✅ Валидация команд с красными сообщениями об ошибках

## Использование

### Создание waypoint
```
.gps X Z название
```

**Примеры:**
- `.gps 100 200 Дом` - создаст waypoint "Дом" на координатах X:100, Z:200
- `.gps -500 1000 Ферма мобов` - создаст waypoint "Ферма мобов" на координатах X:-500, Z:1000
- `.gps 0 0 Спавн` - создаст waypoint "Спавн" на координатах X:0, Z:0

### Важно!
- ❌ **НЕ вводите Y координату!** Модуль использует только X и Z
- ❌ Неправильно: `.gps 100 64 200 Дом` (три числа)
- ✅ Правильно: `.gps 100 200 Дом` (два числа + название)

### Ошибки
Если вы введете команду неправильно, вы увидите красное сообщение:
```
§c§lSolution Visual § 8» §c§lНадо ввести только X и Z координаты и название
```

### Если ввести просто `.gps`
Команда `.gps` без аргументов будет отправлена в чат как обычное сообщение (не перехватывается модулем).

## Настройки модуля

### Цвет рамки
Настраивает цвет рамки вокруг названия waypoint и цвет стрелки.

### Цвет текста
Настраивает цвет текста названия waypoint.

### Макс. дистанция
Максимальное расстояние (в блоках), на котором waypoint будет виден.
- По умолчанию: 1000 блоков
- Диапазон: 100-5000 блоков

### Показывать дистанцию
Включает/выключает отображение расстояния до waypoint рядом с названием.
- По умолчанию: Включено

### Размер стрелки
Настраивает размер стрелки, указывающей на блок.
- По умолчанию: 0.5
- Диапазон: 0.2-2.0

## Визуализация

### 3D элементы
1. **Рамка с названием** - парит над точкой на высоте игрока + 2.5 блока
   - Градиентный фон (от цвета рамки к темному)
   - Яркая рамка по краям
   - Название waypoint
   - Расстояние в метрах (если включено)

2. **Стрелка** - указывает на блок под waypoint
   - Использует текстуру `gps_arrow.png`
   - Повернута на 180° (смотрит вниз)
   - Цвет соответствует цвету рамки

### Billboard эффект
Все элементы всегда повернуты к игроку (billboard), что обеспечивает хорошую видимость с любого угла.

## Технические детали

### Формат команды
```
.gps <X:число> <Z:число> <название:текст>
```

### Валидация
- Проверка на наличие минимум 3 аргументов (X, Z, название)
- Проверка, что первые два аргумента - числа
- Проверка, что третий аргумент - НЕ число (чтобы избежать ввода Y координаты)

### Хранение
Waypoints хранятся в памяти во время работы модуля. При отключении модуля все waypoints удаляются.

## Примеры использования

### Сценарий 1: Отметить дом
```
.gps 250 -180 Мой дом
```
Результат: Waypoint "Мой дом" создан на X:250 Z:-180

### Сценарий 2: Отметить ферму
```
.gps -1000 500 Ферма пшеницы
```
Результат: Waypoint "Ферма пшеницы" создан на X:-1000 Z:500

### Сценарий 3: Ошибка - три координаты
```
.gps 100 64 200 Дом
```
Результат: **Ошибка!** Надо ввести только X и Z координаты и название

### Сценарий 4: Ошибка - нет названия
```
.gps 100 200
```
Результат: **Ошибка!** Надо ввести только X и Z координаты и название

## Советы

1. **Используйте понятные названия** - "Дом", "Ферма", "Шахта" лучше, чем "Точка1"
2. **Настройте цвета** - выберите цвета, которые хорошо видны на фоне неба
3. **Регулируйте дистанцию** - если waypoints мешают, уменьшите максимальную дистанцию
4. **Размер стрелки** - увеличьте, если стрелку плохо видно издалека
