# Контекстное меню с анимацией

## Описание

Реализовано плавное анимированное контекстное меню, которое появляется при нажатии ПКМ в чате или любом GUI.

## Особенности

### 🎨 Анимации

1. **Плавное появление** - меню появляется с эффектом масштабирования (scale) и прозрачности (alpha)
   - Используется `EASE_OUT_ELASTIC` для эффекта "bounce" (колбасит)
   - Длительность: 400ms для масштаба, 300ms для прозрачности

2. **Эффект "колбасы"** - после появления меню слегка покачивается
   - Затухающая синусоида с 4 колебаниями
   - Длительность: 600ms
   - Максимальный угол поворота: ±3 градуса

3. **Плавное закрытие** - при нажатии ESC или клике вне меню
   - Обратная анимация масштаба и прозрачности
   - Меню исчезает плавно

4. **Blur эффект** - меню имеет размытые края и полупрозрачный фон
   - Закругленные углы (radius: 10px)
   - Softness: 2.0
   - Полупрозрачный фон с альфа-каналом

### 🎯 Функционал

- **Открытие**: ПКМ в любом месте чата или GUI
- **Закрытие**: 
  - Нажатие ESC
  - Клик вне меню
  - Клик по пункту меню (после выполнения действия)
- **Интерактивность**: 
  - Подсветка пунктов при наведении
  - Плавная анимация подсветки

### 📝 Пункты меню (примеры)

По умолчанию добавлены следующие пункты:
- 📋 Копировать
- 📝 Вставить
- ✂ Вырезать
- 🔄 Обновить
- ⚙ Настройки

## Технические детали

### Файлы

1. **ContextMenu.java** - основной класс меню
   - Управление анимациями
   - Рендеринг меню и пунктов
   - Обработка взаимодействий

2. **ScreenMixin.java** - миксин для Screen
   - Перехват ПКМ
   - Рендеринг меню поверх GUI
   - Обработка клавиш (ESC)

### Система анимаций

Используется существующая система анимаций проекта:
- `Animation` - класс для управления анимацией
- `Easing` - набор функций плавности
  - `EASE_OUT_ELASTIC` - для bounce эффекта
  - `EASE_OUT_CUBIC` - для плавного затухания
  - `EASE_OUT_SINE` - для покачивания

### Параметры меню

```java
private float width = 150f;          // Ширина меню
private float itemHeight = 28f;      // Высота пункта
private float padding = 6f;          // Отступы
private float cornerRadius = 10f;    // Радиус закругления
```

### Анимационные параметры

```java
// Масштаб с bounce эффектом
Animation scaleAnimation = new Animation(Easing.EASE_OUT_ELASTIC, 400);

// Прозрачность
Animation alphaAnimation = new Animation(Easing.EASE_OUT_CUBIC, 300);

// Покачивание
Animation wobbleAnimation = new Animation(Easing.EASE_OUT_SINE, 600);
```

## Использование

### Добавление пунктов меню

Отредактируйте метод `createContextMenu()` в `ScreenMixin.java`:

```java
private static ContextMenu createContextMenu() {
    ContextMenu menu = new ContextMenu();
    
    menu.addItem("Название", () -> {
        // Действие при клике
    });
    
    return menu;
}
```

### Настройка внешнего вида

Параметры можно изменить в конструкторе `ContextMenu`:

```java
private float width = 150f;      // Ширина
private float itemHeight = 28f;  // Высота пункта
private float padding = 6f;      // Отступы
```

### Настройка анимаций

Измените параметры в конструкторе:

```java
// Изменить тип плавности и длительность
private final Animation scaleAnimation = new Animation(Easing.EASE_OUT_BACK, 500);
```

Доступные типы Easing:
- `EASE_OUT_ELASTIC` - bounce эффект (текущий)
- `EASE_OUT_BACK` - небольшой overshoot
- `EASE_OUT_CUBIC` - плавное затухание
- `EASE_OUT_QUART` - более резкое затухание
- И другие (см. `Easing.java`)

## Визуальные эффекты

### Blur и закругление

Меню использует `blur.render()` с параметрами:
- `round(10)` - радиус закругления углов
- `softness(2.0f)` - мягкость размытия
- `thickness(1.5f)` - толщина обводки

### Цвета

Цвета берутся из текущей темы:
```java
Color themeCol = ThemeManager.getInstance().getCurrentTheme().getBackgroundColor();
```

- Фон: цвет темы с альфа 160
- Обводка: цвет темы с альфа 200
- Текст: белый с альфа 200 (255 при наведении)
- Подсветка: белый с альфа 30

## Производительность

- Анимации обновляются только когда меню видимо
- Меню создается один раз и переиспользуется
- Рендеринг оптимизирован с использованием Tessellator
- Кэширование цветов для избежания аллокаций
