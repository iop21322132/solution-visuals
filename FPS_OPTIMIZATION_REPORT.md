# Отчёт по оптимизации FPS

## ✅ Выполненные оптимизации

### 1. ✅ Устранены аллокации векторов в рендерерах
**Проблема**: Каждый кадр создавались новые `Vector3f` и `Vector4f` объекты в `Blur`, `Rectangle`, `Arc`
**Решение**: Добавлены кэшированные векторы, которые переиспользуются
**Файлы**:
- `src/main/java/farvix/solution/api/render/rect/impl/Blur.java`
- `src/main/java/farvix/solution/api/render/rect/impl/Rectangle.java`
- `src/main/java/farvix/solution/api/render/rect/impl/Arc.java`

**Эффект**: Уменьшение аллокаций на ~3-6 объектов на каждый вызов render (сотни раз за кадр)

### 2. ✅ Оптимизация ShapeProperties
**Проблема**: Создание новых `Vector4f(0)` для каждого элемента без скругления
**Решение**: Кэширование `ZERO_ROUND` вектора для переиспользования
**Файл**: `src/main/java/farvix/solution/api/render/rect/ShapeProperties.java`

**Эффект**: Уменьшение аллокаций для элементов без скругления

### 3. ✅ Кэширование Color объектов в CustomHitbox
**Проблема**: Создание новых Color объектов для каждой сущности каждый кадр (50+ сущностей = 200+ объектов)
**Решение**: Кэшируем `outlineColor`, `fillColor1`, `fillColor2` и пересоздаём только при изменении настроек
**Файл**: `src/main/java/farvix/solution/client/modules/impl/visuals/CustomHitbox.java`

**Эффект**: Уменьшение аллокаций с ~200+ до ~3 объектов за кадр при наличии сущностей

### 4. ✅ Кэширование FixColor в TargetHud
**Проблема**: Создание 6+ FixColor объектов каждый кадр для текста и UI элементов
**Решение**: Кэшируем все часто используемые цвета, пересоздаём только при изменении alpha
**Файл**: `src/main/java/farvix/solution/client/modules/impl/visuals/TargetHud.java`

**Эффект**: Уменьшение аллокаций с ~6 до 0 объектов за кадр (пересоздаются только при fade in/out)

### 5. ✅ Кэширование Color в DynamicIsland
**Проблема**: Создание 8+ Color/FixColor объектов каждый кадр для текста, иконок и индикаторов
**Решение**: Кэшируем все цвета, пересоздаём только при изменении alpha анимаций
**Файл**: `src/main/java/farvix/solution/client/modules/impl/visuals/DynamicIsland.java`

**Эффект**: Уменьшение аллокаций с ~8 до 0 объектов за кадр

## ⚠️ Критические проблемы (требуют внимания)

### ⚠️ 1. blur.setup() вызывается каждый кадр
**Файл**: `src/main/java/farvix/solution/mixins/InGameHudMixin.java:29`

```java
@Inject(method = "render", at = @At("RETURN"))
public void onRender(DrawContext context, RenderTickCounter tickCounter, CallbackInfo ci) {
    blur.setup();  // ← ОЧЕНЬ ТЯЖЁЛАЯ ОПЕРАЦИЯ!
    new EventRender2D(context, tickCounter).call();
}
```

**Проблема**: 
- `blur.setup()` копирует весь framebuffer в текстуру
- Это происходит 60+ раз в секунду
- Очень тяжело для GPU

**Рекомендация**: 
- Вызывать `blur.setup()` только когда действительно нужен blur эффект
- Или оптимизировать метод setup() чтобы он не копировал framebuffer если ничего не изменилось
- Добавить настройку "Отключить blur эффекты" для слабых ПК
