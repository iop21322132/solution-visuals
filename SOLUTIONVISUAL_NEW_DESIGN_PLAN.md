# SolutionVisual GUI - Новый Дизайн (Темная Тема)

## 📋 Обзор

Полное переосмысление GUI в стиле современного темного интерфейса с blur эффектами, вертикальной навигацией и карточками модулей.

---

## 🎨 Дизайн Концепция

### Цветовая Схема
- **Фон GUI**: Темный с blur эффектом (rgba(20, 20, 25, 0.95))
- **Карточки модулей**: Темно-серые с легким blur (rgba(30, 30, 35, 0.9))
- **Акценты**: Белый текст, цветные иконки категорий
- **Hover эффекты**: Легкое осветление (rgba(40, 40, 45, 0.9))
- **Активные элементы**: Акцентный цвет темы

### Типографика
- **Заголовки**: Средний размер, полужирный
- **Названия модулей**: Обычный размер, нормальный вес
- **Описания**: Маленький размер, серый цвет (rgba(150, 150, 160, 1))

## 🏗️ Компоненты

### 1. Главное Окно (SolutionGuiScreen)
**Размеры**: 
- Ширина: 60% экрана
- Высота: 70% экрана
- Позиция: По центру экрана

**Особенности**:
- Blur фон экрана за GUI (как на скриншотах)
- Темный фон с blur эффектом
- Скругленные углы (12px)
- Тонкая светлая рамка (1px, rgba(60, 60, 70, 0.3))

### 2. Верхняя Панель (Header)
**Компоненты**:
- **Логотип**: 🔥 иконка + "SolutionVisual" текст (слева)
- **Поиск**: Поле поиска по центру
- **Настройки**: ⚙️ иконка (справа)

**Размеры**:
- Высота: 60px
- Padding: 15px

### 3. Боковая Панель Категорий (CategorySidebar)
**Размеры**:
- Ширина: 80px
- Высота: 100% (от header до низа)

**Категории** (вертикально):
1. 🔥 **VISUALS** - Визуальные эффекты
2. 📷 **HUD** - HUD элементы
3. 👤 **PLAYER** - Игрок
4. ⚙️ **UTILITIES** - Утилиты
5. 📁 **CONFIGS** - Конфиги
6. 🌍 **WORLD** - Мир

**Стиль кнопок**:
- Размер: 60x60px
- Скругление: 12px
- Hover: Легкое осветление + scale 1.05
- Active: Акцентный цвет фона

### 4. Область Модулей (ModuleGrid)
**Размеры**:
- Ширина: Оставшееся пространство справа от sidebar
- Высота: 100% (от header до низа)
- Padding: 20px

**Сетка**:
- 2 колонки
- Gap между карточками: 15px
- Скролл: Вертикальный (если не помещается)

### 5. Карточка Модуля (ModuleCard)
**Размеры**:
- Ширина: Авто (50% - gap)
- Высота: Авто (минимум 80px)
- Padding: 15px

**Структура**:
```
┌────────────────────────────┐
│ ModuleName            ⚙️   │
│ Краткое описание модуля    │
└────────────────────────────┘
```

**Состояния**:
- **Выключен**: Темно-серый фон
- **Включен**: Легкий акцентный оттенок
- **Hover**: Осветление + тень
- **Клик на ⚙️**: Открыть настройки модуля

### 6. Панель Настроек Модуля (ModuleSettings)
**Появление**: Справа от карточки (slide-in анимация)

**Компоненты**:
- **Заголовок**: Название модуля + кнопка закрытия
- **Настройки**: Список настроек (toggle, slider, color picker, etc.)

**Типы настроек**:
1. **Toggle** (BooleanSetting)
   - Переключатель справа
   
2. **Slider** (NumberSetting)
   - Ползунок с значением
   - Название слева, значение справа
   
3. **Color Picker** (ColorSetting)
   - Квадрат с цветом
   - Клик открывает палитру (как на 3-м скриншоте)
   
4. **Dropdown** (ListSetting)
   - Выпадающий список
   
5. **Multi Select** (MultiSetting)
   - Чекбоксы для множественного выбора

### 7. Поле Поиска (SearchField)
**Размеры**:
- Ширина: 300px
- Высота: 40px

**Особенности**:
- 🔍 иконка слева
- Placeholder: "Поиск..."
- Темный фон с blur
- Скругленные углы (8px)
- Фильтрация модулей в реальном времени

## 🎭 Анимации

### Открытие GUI
1. **Blur фона**: 0 → 1 (300ms, ease-out)
2. **Scale GUI**: 0.95 → 1.0 (300ms, ease-out-cubic)
3. **Fade GUI**: 0 → 1 (300ms, ease-out)

### Переключение Категорий
1. **Fade out старые карточки**: 1 → 0 (200ms)
2. **Fade in новые карточки**: 0 → 1 (200ms, delay 100ms)
3. **Slide карточек**: translateY(20px) → 0 (300ms, ease-out)

### Hover Эффекты
- **Карточка модуля**: scale 1.0 → 1.02 (150ms)
- **Кнопка категории**: scale 1.0 → 1.05 (150ms)
- **Кнопка настроек**: rotate 0° → 90° (200ms)

### Открытие Настроек
- **Slide in**: translateX(100%) → 0 (300ms, ease-out-cubic)
- **Fade in**: 0 → 1 (300ms)
