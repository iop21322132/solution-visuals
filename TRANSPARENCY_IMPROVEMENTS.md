# Увеличение Прозрачности GUI

## Проблема
Пользователь хотел увеличить прозрачность GUI, чтобы больше просвечивал игровой мир через интерфейс.

## Решение
Уменьшены значения alpha (прозрачности) для всех фоновых элементов GUI в файле `TempColor.java`.

## Технические Детали

### Что такое Alpha?
Alpha - это канал прозрачности в цвете RGBA:
- **255** = полностью непрозрачный (0% прозрачности)
- **200-220** = почти непрозрачный (~15-20% прозрачности)
- **140-180** = полупрозрачный (~30-45% прозрачности) ← **новые значения**
- **100** = очень прозрачный (~60% прозрачности)
- **0** = полностью прозрачный (100% прозрачности)

### Формула прозрачности:
```
Прозрачность % = (255 - Alpha) / 255 * 100
```

### Примеры:
- Alpha 220 → ~14% прозрачности
- Alpha 180 → ~29% прозрачности ✅ (GUI Background)
- Alpha 140 → ~45% прозрачности ✅ (Module Background)
