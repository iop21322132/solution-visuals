# Тестирование Контекстного Меню

## Что Добавлено

✅ **PotionEffects** теперь поддерживает контекстное меню при ПКМ

## Как Протестировать

### 1. Включите модуль Potion Effects

1. Откройте ClickGUI
2. Найдите модуль "Potion Effects" в категории Visuals
3. Включите его (ЛКМ)

### 2. Получите эффект зелья

В игре выполните команду:
```
/effect give @s minecraft:speed 60 1
```

Или используйте любое зелье из инвентаря.

### 3. Тест: ПКМ по окну Potions

1. На экране должно появиться окно "Potions" с эффектами
2. **ПКМ по окну "Potions"** → Должно открыться меню с:
   - ⚙️ Настроить
   - 🗑️ Удалить

### 4. Тест: Кнопка "Настроить"

1. Откройте меню (ПКМ по окну Potions)
2. **ЛКМ по "Настроить"** → Должны раскрыться настройки модуля в ClickGUI
3. Проверьте что настройки видны (Размер, Прозрачность фона)

### 5. Тест: Кнопка "Удалить"

1. Откройте меню (ПКМ по окну Potions)
2. **ЛКМ по "Удалить"** → Модуль должен выключиться
3. Окно "Potions" должно исчезнуть
4. В чате должно появиться сообщение: "§cМодуль Potion Effects выключен"

### 6. Тест: ПКМ по пустому месту

1. **ПКМ вне окна Potions** (на пустом месте) → Должно открыться обычное меню:
   - 📋 Копировать
   - 📝 Вставить
   - ✂️ Вырезать
   - 🔄 Обновить
   - ⚙️ Настройки

### 7. Тест: ПКМ в ClickGUI

1. Откройте ClickGUI
2. **ПКМ внутри окна GUI** (но не по модулю) → Ничего не должно происходить
3. **ПКМ по модулю в ClickGUI** → Должны раскрыться настройки модуля (как раньше)

### 8. Тест: Перетаскивание

1. Откройте чат или ClickGUI
2. **ЛКМ + перетащите окно Potions** → Окно должно перемещаться
3. **ПКМ по новой позиции** → Меню должно открываться в новой позиции

### 9. Тест: Масштабирование

1. Откройте ClickGUI
2. Найдите модуль "Potion Effects"
3. ПКМ чтобы раскрыть настройки
4. Измените "Размер" (например на 1.5x)
5. Закройте ClickGUI
6. **ПКМ по окну Potions** → Меню должно открываться правильно независимо от масштаба

## Ожидаемые Результаты

| Действие | Ожидаемый Результат |
|----------|---------------------|
| ПКМ по окну Potions | Меню модуля (Настроить, Удалить) |
| ПКМ по пустому месту | Обычное меню (Копировать, Вставить...) |
| ПКМ в ClickGUI | Ничего (или раскрытие настроек модуля) |
| Клик "Настроить" | Раскрываются настройки в ClickGUI |
| Клик "Удалить" | Модуль выключается |
| ESC при открытом меню | Меню закрывается |
| Клик вне меню | Меню закрывается |

## Возможные Проблемы

### Меню не открывается

**Причина:** Модуль не зарегистрирован в реестре

**Решение:** 
1. Проверьте что модуль включен
2. Проверьте что `onEnable()` вызывается
3. Добавьте debug логирование в `HudElementRegistry.register()`

### Меню открывается не в том месте

**Причина:** Координаты не учитывают масштабирование

**Решение:**
1. Проверьте что `getHudWidth()` и `getHudHeight()` умножают на `scale.getValue()`
2. Проверьте что координаты не трансформированы

### Клик проходит "сквозь" окно

**Причина:** Другой HUD элемент перекрывает

**Решение:**
1. Проверьте порядок регистрации элементов
2. Проверьте что `isHovered()` возвращает `true`

## Debug Логирование

Если что-то не работает, добавьте debug логирование:

```java
@Override
public boolean isHovered(double mouseX, double mouseY) {
    boolean result = IHudElement.super.isHovered(mouseX, mouseY);
    if (mc.player != null) {
        mc.player.sendMessage(
            net.minecraft.text.Text.literal(
                "§ePotionEffects.isHovered: " + result + 
                ", mouse=(" + (int)mouseX + "," + (int)mouseY + ")" +
                ", bounds=(" + (int)getHudX() + "," + (int)getHudY() + 
                "," + (int)getHudWidth() + "," + (int)getHudHeight() + ")"
            ), 
            false
        );
    }
    return result;
}
```
