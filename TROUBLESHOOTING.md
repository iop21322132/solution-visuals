# Устранение проблем

## ✅ Исправлено: Mixin transformation error

### Проблема
```
Caused by: java.lang.RuntimeException: Mixin transformation of net.minecraft.client.gui.screen.Screen failed
InvalidInjectionException: @Inject annotation on onMouseClicked could not find any targets matching 'mouseClicked'
```

### Решение
**Полностью изменен подход!** Вместо проблемного миксина в `Screen`, контекстное меню теперь реализовано как **модуль**.

### Что было изменено:
1. ❌ Удален `ScreenMixin.java` (вызывал краш)
2. ✅ Создан `ContextMenuModule.java` - модуль для управления меню
3. ✅ Модуль зарегистрирован в `ModuleManager`
4. ✅ Меню работает через события `EventRender2D`

### Текущий статус
✅ Компиляция успешна  
✅ Нет проблемных миксинов  
✅ Модуль работает стабильно  

## ⚠️ ВАЖНО: Как включить меню

Контекстное меню теперь **модуль**, который нужно включить:

1. Откройте меню модов (Insert или ClickGUI)
2. Найдите **"Context Menu"** в категории **Visuals**
3. **Включите** модуль
4. Теперь ПКМ в GUI будет открывать меню!  

## Предупреждения компиляции

### Warning: Unable to determine descriptor for @Inject target method
Это **не ошибка**, а предупреждение. Миксин будет работать корректно в runtime.

**Причина**: Mixin не может определить точную сигнатуру метода на этапе компиляции, но найдет её в runtime.

**Решение**: Игнорировать. Это нормальное поведение для некоторых миксинов.

## Тестирование

### Как проверить что всё работает:

1. Запустите игру
2. **Включите модуль "Context Menu"** в меню модов
3. Откройте чат (T) или любой GUI (E)
4. Нажмите **ПКМ** в любом месте
5. Должно появиться меню с анимацией
6. Нажмите **ESC** - меню должно плавно закрыться

### Если меню не появляется:

1. **Проверьте что модуль включен!** (самая частая причина)
2. Откройте меню модов и найдите "Context Menu"
3. Убедитесь что модуль активен (зеленый/включен)
4. Попробуйте переключить модуль (выкл/вкл)

### Если анимация не плавная:

1. Проверьте FPS - анимация зависит от частоты кадров
2. Измените параметры анимации в `ContextMenu.java`:
   ```java
   // Увеличьте длительность для более медленной анимации
   new Animation(Easing.EASE_OUT_ELASTIC, 600); // было 400
   ```

## Известные ограничения

1. **Миксин применяется ко всем Screen**
   - Меню будет доступно во всех GUI
   - Если нужно ограничить - добавьте проверку типа экрана

2. **ПКМ перехватывается всегда**
   - Может конфликтовать с другими модами
   - Решение: добавить проверку на конфликты

3. **Статическое меню**
   - Меню создается один раз для всех экранов
   - Если нужно разное меню для разных экранов - измените логику

## Оптимизация

### Если меню тормозит:

1. Уменьшите количество сегментов в `drawRoundedRect`:
   ```java
   int segments = 4; // было 8
   ```

2. Отключите wobble эффект:
   ```java
   // Закомментируйте в render():
   // if (wobble != 0) { ... }
   ```

3. Упростите blur:
   ```java
   .softness(1.0f) // было 2.0f
   ```


### Добавить горячую клавишу

Добавьте в `onKeyPressed`:

```java

    if (contextMenu == null) {
        contextMenu = createContextMenu();
    }
    contextMenu.open(width / 2f, height / 2f); // По центру
    cir.setReturnValue(true);
}
```

### Отключить в определенных GUI

```java

if (screen instanceof InventoryScreen) {
    return; // Не открывать в инвентаре

```
