## Технические Детали

### Настройка в ClickUI

```java
public final Setting<Boolean> particles = new Setting<>("Particles", true)
        .setDescription("Показывать летние частицы на фоне GUI");
```

### Параметры Частиц

**Движение:**
- Горизонтальная скорость: -0.25 до +0.25 px/frame
- Вертикальная скорость: 0.1 до 0.4 px/frame (падение)
- Покачивание: sin(lifetime * 2) * 0.3

**Визуал:**
- Размер: 1.5-3.5 px
- Форма: круг с мягким свечением (softness 1.5)
- Прозрачность: 0-180 (с fade in/out)
- Lifetime: 2-5 секунд

**Цвета:**
- Желтый: RGB(255, 220, 100)
- Оранжевый: RGB(255, 180, 100)
- Светло-зеленый: RGB(150, 255, 150)
- Голубой: RGB(150, 200, 255)

### Оптимизация

- Фиксированное количество частиц (40)
- Переиспользование объектов (reset вместо создания новых)
- Рендеринг только видимых частиц (alpha > 0.01)
- Легковесные вычисления

## Как Проверить

1. **Открой ClickGUI** (правый Shift)
2. **Посмотри на фон** - увидишь плавающие светящиеся точки
3. **Цвета** - желтые, оранжевые, зеленые и голубые искры
4. **Движение** - медленно падают вниз с покачиванием
5. **Настройка** - открой настройки ClickUI модуля → переключи "Particles"
